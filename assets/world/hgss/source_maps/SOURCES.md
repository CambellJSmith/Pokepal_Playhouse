# HGSS world map sources

`download_hgss_world_tiles.sh` downloads these HeartGold/SoulSilver game-map images from Bulbagarden Archives:

- `Johto_Route_29_HGSS.png`
- `Kanto_Route_6_HGSS.png`
- `Kanto_Route_5_HGSS.png`

The downloaded PNGs are local development assets and remain Git-ignored. They are screenshots/substantially game-derived images; Bulbagarden Archives labels them as fair-use game images.
